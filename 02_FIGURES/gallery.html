视觉布局（v1.0-cand.4 reviewer-audit 重构）

  • Row 1 — 双语料显式化：左侧实线框 = Main RTAS corpus（3,714 ITTP projects (CN) + 56,901 OpenAlex papers (EN)，2020–2024）；右侧灰虚线框 = Auxiliary advisor-history corpus（22,438 OpenAlex papers 2017–2019 → 仅喂 HLM 立项前协变量窗口 [t−3, t−1]）。修正旧版"单一语料"的表述性错误。
  • Row 2 — 方法流水线：Embedding（Multilingual MiniLM L12-v2, 384-dim；Pairwise semantic validity ρ_s = .405 (n=150, p=2.6e-7) 置于 Embedding 框——它是 embedding 级指标，5 种聚合变体共享）→ RTAS Computation（Cosine similarity + Mean + Cumulative [2020, t]）→ RTAS Frozen（改为变体选择陈述：5 aggregation variants tested; Primary = mean (composite score .742)，不再承载效度数字）。
  • Row 3 — 四大分析模块：Heterogeneity (RQ1, F=35.7, η²=1.89%) / BERTopic (RQ2, K=886, 4-quadrant) / Matthew (RQ4, Gini=0.767, lag-OR=2.25***) / HLM (RQ3, ICC=0.738, 39 colleges, clean prior supervision)。
  • Row 4 — Diffusion Lag (RQ2)：29/886 defined, HRLT median +0.5 yr。
  • RI-CLPM "future work" 框整体删除：从未估计的模型不应出现在方法图内；如需叙述移入手稿 Limitations / Future Work。
  • 箭头语义：实线 = 主语料数据流（main→embedding；embedding→computation→frozen；frozen/embedding→各分析模块；BERTopic→Diffusion）；虚线 = 辅助语料 aux→HLM 绕行连接；v1.0-cand.5 起 Heterogeneity 由 RTAS Frozen 正交肘线下传（异质性分析对象是冻结 RTAS，不再从 main corpus 直连），全部箭头采用正交肘线、绝不穿过方框本体。
  • 颜色语义：蓝=数据源 / 青=Embedding / 绿=计算 / 深蓝=冻结 / 橙=BERTopic / 红=马太 / 紫=HLM / 灰=扩散与辅助语料（虚线框）。

如何阅读

主语料（项目+论文）→ Embedding（ρ_s = .405 在此）→ RTAS 计算 → 冻结（mean 变体以综合分 .742 胜出）。冻结 RTAS + embeddings 下传四大分析模块：异质性 / BERTopic 四象限（再下传扩散滞后）/ 马太 / HLM。辅助导师历史语料（2017–2019, 22,438 篇）虚线直喂 HLM 的立项前协变量窗口——双语料各司其职，杜绝"单语料"误读。
