# Public snapshot integrity — RTAS

The historical checksum manifest enumerated private input filenames, local analysis artefacts, and an obsolete compiled-paper snapshot. Those private paths, file sizes, and stale checksums are intentionally not reproduced in the current public snapshot.

The public repository snapshot is identified by its Git commit and tree object IDs. The public repository does not include raw project records, advisor-linkage tables, embedding arrays, or the original validation title-pair mapping. No checksum for a private file should be published alongside this repository.
